# Security Policy

## Supported Versions

Security fixes are applied to the latest commit on the `main` branch. This repository does not currently maintain release branches.

## Reporting a Vulnerability

For vulnerabilities that could expose credentials, execute untrusted downloads, modify unintended files, bypass validation, or weaken service security, do not open a public issue.

Use GitHub's private security-advisory reporting for this repository when it is available. Otherwise, contact the repository owner privately through their GitHub profile with:

- affected script and commit hash;
- a minimal, sanitized reproduction;
- impact and suggested mitigation.

Do not include passwords, API keys, webhook URLs, private certificates, or production configuration files. Reports are acknowledged after triage; a fix and coordinated disclosure timeline are provided when the issue is confirmed.
